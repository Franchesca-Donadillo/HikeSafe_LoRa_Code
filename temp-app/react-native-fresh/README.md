# HikeSafe React Native (Fresh)

This is a fresh Expo SDK48 project with the chat UI included. Use this if the earlier project got package mismatches from `npm audit fix --force`.

Quick start (PowerShell):

```powershell
cd "temp-app/react-native-fresh"
npm install
npx expo start -c
```

Open the QR code in Expo Go on your phone (ensure Expo Go is up to date). Set the gateway URL in the app UI to `ws://<GATEWAY_HOST>:8080` and connect.
